# Ueats Automation Test Project

This project contains automated tests for Ueats, a Command Line Interface (CLI) tool developed as part of my pytest Udemy course.

## Course Reference

This project is associated with the Udemy course:

- Pytest Mastery: From Beginner to Pro in Automation Testing — https://www.udemy.com/course/pytest-automation-testing

## Prerequisites

Before running the tests, ensure you have the following installed:

- Python > 3.8
- ueats cli
- pytest

## Running the Tests

To run the automated tests, navigate to the project root directory and run:

```bash
pytest
